Over mij

Ik ben Jillert Sijens, 23 jaar en woon in Lichtaard. Ik ben afgestudeerd als mediavormgever/graphic designer en studeer nu HBO ICT aan NHL Stenden in Leeuwarden, met Software Engineering als richting. Dankzij mijn achtergrond in design let ik er bij het maken van software ook op dat het er goed uitziet en prettig in gebruik is. Later wil ik van deze combinatie mijn werk maken als fullstack webdeveloper.

Op dit moment ben ik op zoek naar een stageplek als software engineer. Op deze website vind je mijn werk, zowel mijn designs als de projecten die ik heb gemaakt en aan mee heb geholpen.
